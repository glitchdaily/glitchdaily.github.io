Privacy Policy

Last updated: November 9, 2026

Who we are

Glitch Daily is a YouTube channel. Its owner operates a private application called “youtube-agent” that helps create videos and upload them to the Glitch Daily channel. The application is used only by the channel owner and is not offered to the public.

YouTube API Services

youtube-agent uses the YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google’s handling of data is described in the Google Privacy Policy.

What data the application accesses

  • The basic details of the channel owner’s own YouTube channel (channel name and ID).
  • Upload and management access to that channel, used only to publish and update the channel’s own videos.
  • Analytics for that channel, used only to help the owner decide what content to make next.

The application does not collect, access or store personal data of viewers or of any other YouTube user.

How data is stored and shared

Authorization tokens and channel information are stored only on the channel owner’s own computer. They are not sent to any third-party server, sold, or shared, except with Google as needed to call the YouTube API, and with the AI text service the owner configures to write video scripts (which receives only topic and script text, never account credentials).

Revoking access

Access can be revoked at any time from the Google account’s security settings: security.google.com/settings/security/permissions. Deleting the application’s local files also deletes all stored data.
