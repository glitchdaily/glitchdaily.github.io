Privacy Policy

Last updated: November 10, 2026

Who we are

Glitch Daily is a YouTube channel. Its owner operates a private application called Glitch Daily Publisher that helps create videos and upload them to the Glitch Daily channel. The application is used only by the channel owner and is not offered to the public.

YouTube API Services

Glitch Daily Publisher uses the YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google’s handling of data is described in the Google Privacy Policy.

What data the application accesses

  • The basic details of the channel owner’s own YouTube channel (channel name and ID).
  • Upload and management access to that channel, used only to publish and update the channel’s own videos, thumbnails and captions.
  • Analytics and public statistics (views, likes, comment counts) for that channel’s own videos, used only to help the owner decide what content to make next.
  • Comments posted on the channel’s own videos, read so the owner can see and reply to them.

The application does not collect personal data of viewers or of any other YouTube user beyond what is shown publicly on the channel’s own videos, and it never sells or shares such data.

How data is used, stored and shared

Authorization tokens and channel information are stored only on the channel owner’s own computer. They are not sent to any third-party server, sold, or shared, except with Google as needed to call the YouTube API Services, and with the AI text service the owner configures to write video scripts (which receives only topic and script text, never account credentials or YouTube user data).

The application does not use cookies or tracking on this website.

Data retention and deletion

Data obtained from the YouTube API Services is kept on the owner’s computer only as long as needed, and is refreshed or deleted within 30 days, as required by the YouTube API Services Developer Policies. Deleting the application’s local files deletes all stored data immediately.

To ask for any data about you to be deleted, email maxime.billot.creation@gmail.com; requests are handled within 7 days.

Revoking access

Access granted to Glitch Daily Publisher can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions.

Changes

Any change to this policy will be published on this page with a new “Last updated” date.
